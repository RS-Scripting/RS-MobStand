# Pause and Resume

The Pause feature allows you to temporarily disable a Mob Stand without removing it or changing its configuration.

This is useful when performing maintenance, redesigning farms, or temporarily stopping resource generation.

---

# What Pause Does

When a Mob Stand is paused:

```text id="hldq1q"
Processing Stops
```

The Mob Stand remains fully configured but will not manage mobs until processing is resumed.

All settings remain intact, including:

* Radius
* Leave Alive
* Adult Filters
* Baby Filters
* Gravity Settings

---

# What Pause Does Not Do

Pausing a Mob Stand does not:

* Remove the Mob Stand
* Reset any settings
* Change ownership
* Affect filter configuration
* Convert the Mob Stand back into an Armor Stand

Think of Pause as an on/off switch for processing.

---

# Pausing a Mob Stand

Open:

```text id="s41m2x"
Main Menu
    ↓
Pause Processing
```

Once paused, the Mob Stand will stop managing nearby mobs.

---

# Resuming a Mob Stand

Open:

```text id="8dxvt0"
Main Menu
    ↓
Resume Processing
```

The Mob Stand immediately returns to normal operation using its existing configuration.

---

# Why Use Pause?

Common reasons include:

### Farm Maintenance

Temporarily stop processing while making changes to a farm.

### Testing Configurations

Experiment with settings without permanently changing farm behavior.

### Resource Management

Disable production until resources are needed.

### Seasonal Events

Temporarily disable farms without removing player setups.

---

# Visual Indicators

The Pause button displays the current state of the Mob Stand.

### Processing Enabled

The Mob Stand is actively managing nearby mobs.

### Processing Disabled

The Mob Stand is paused and will not process mobs.

---

# Tips

### Use Pause Before Major Changes

If you're redesigning a farm, pause the Mob Stand first.

### No Reconfiguration Required

After resuming, all previous settings remain unchanged.

### Safe to Leave Paused

A Mob Stand can remain paused indefinitely until processing is resumed.
