# Gravity Settings

The Gravity setting controls whether a Mob Stand is affected by Minecraft's normal gravity mechanics.

This allows players to create both grounded and floating Mob Stand designs.

---

# What Gravity Does

When gravity is enabled, the Mob Stand behaves like a normal Armor Stand and will fall if there is no supporting block beneath it.

When gravity is disabled, the Mob Stand remains fixed in place.

---

# Gravity Enabled

With gravity enabled:

```text
Gravity: Enabled
```

The Mob Stand will:

* Fall when unsupported
* React to normal Minecraft physics
* Behave like a standard Armor Stand

This is useful when you want the Mob Stand to remain part of a physical structure.

---

# Gravity Disabled

With gravity disabled:

```text
Gravity: Disabled
```

The Mob Stand will:

* Remain suspended in place
* Ignore normal falling behavior
* Stay exactly where it was positioned

This is useful for:

* Floating displays
* Decorative installations
* Elevated farm layouts
* Difficult-to-reach locations

---

# Changing Gravity

Open:

```text
Main Menu
    ↓
Gravity
```

Click the Gravity option to toggle between enabled and disabled states.

The change takes effect immediately.

---

# Visual Indicator

The Gravity button displays the current state.

### Enabled

The button appears active and indicates that gravity is currently enabled.

### Disabled

The button indicates that gravity is currently disabled.

---

# Tips

### Floating Farm Designs

Disable gravity to keep Mob Stands suspended in midair.

### Ground-Based Farms

Enable gravity if you want the Mob Stand to behave like a normal Armor Stand.

### Building Adjustments

You can temporarily disable gravity while positioning a Mob Stand, then re-enable it afterward if desired.
