# Admin Guide

## Overview
RS-MobStand includes an **Admin** menu for server administrators.
The Admin menu is available to players with operator permissions.

---

## Opening the Admin Menu
To access the Admin menu:

1. Open an RS-MobStand's main menu.
2. Select **Admin**.
3. The Admin menu opens with the available administrative options.

If the Admin option is not available, make sure you have the required operator permissions.

---

## Plugin Version Information
The Admin menu provides information about the installed RS-MobStand version and the latest version available from the project's release information.
This can help administrators determine whether the plugin is up to date.
The version information is also useful when reporting problems or requesting support.

---

## Updating RS-MobStand
When an update is available:

1. Review the version information shown in the Admin menu.
2. Obtain the newer RS-MobStand release.
3. Stop the server.
4. Replace the existing plugin JAR with the newer version.
5. Start the server.
6. Verify that RS-MobStand loads normally.

Always keep a backup of your server before performing plugin updates.

---

## Administration and Mob Stands

The Admin menu is separate from the normal Mob Stand configuration options.

Regular Mob Stand settings such as:

- Adult Filters
- Baby Filters
- Scan Radius
- Leave Alive
- Gravity
- Pause/Resume
- Display Name
- Arm Poses

are configured from the normal Mob Stand menu.
