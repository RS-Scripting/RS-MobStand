# Installation

## Requirements

Before installing RS-MobStand, make sure your server meets the following requirements:

- **Minecraft:** 1.21+
- **Server:** Paper

---

## Installing RS-MobStand

1. Download the latest **RS-MobStand** release.
2. Place the `.jar` file into your server's `plugins` folder.
3. Start or restart your Minecraft server.
4. Verify that RS-MobStand loads successfully.

Once installed, RS-MobStand is ready to use.

---

## Creating Your First Mob Stand

RS-MobStand uses standard Minecraft Armor Stands as its base.

1. Place an **Armor Stand** where you want the Mob Stand to operate.
2. Use the RS-MobStand conversion process on the Armor Stand.
3. The Armor Stand will become an **RS-MobStand**.
4. The newly converted Mob Stand starts **paused**.
5. Open the Mob Stand menu and configure its settings.
6. Configure the mobs you want the stand to manage.
7. Set the desired scan radius and other options.
8. Resume the Mob Stand when you are ready.

Starting paused allows you to completely configure the stand before it begins managing mobs.

---

## Verifying Installation
After starting the server, check the server console for the RS-MobStand startup message.
You can also open a Mob Stand's menu and verify that its configuration options are available.

---

## Updating RS-MobStand
To update RS-MobStand:

1. Stop the Minecraft server.
2. Remove the old RS-MobStand `.jar`.
3. Place the new version into the `plugins` folder.
4. Start the server.

Your existing Mob Stand data and configuration are designed to persist across server restarts and plugin updates.

---

## Uninstalling

To remove RS-MobStand:

1. Stop the Minecraft server.
2. Remove the RS-MobStand `.jar` from the `plugins` folder.
3. Start the server.

Before uninstalling, make sure you no longer need any Mob Stands created by the plugin.
