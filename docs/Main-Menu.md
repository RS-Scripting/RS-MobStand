# Main Menu

The Main Menu is the central control panel for your Mob Stand.

To open it, simply right-click your Mob Stand.

From here you can access all configuration options available to the stand.

---

# Main Menu Options

## Convert Back to Armor Stand

Returns the Mob Stand to a normal Armor Stand.

Use this option if you no longer need automated mob management.

**Warning:** Any Mob Stand configuration will be removed.

---

## Admin Menu

**Operators Only**

Provides access to administrative tools and plugin information.

This option is only visible to server operators and administrators.

---

## Pause / Resume Processing

Temporarily enables or disables Mob Stand processing.

### When Enabled

The Mob Stand will continue managing nearby mobs normally.

### When Disabled

The Mob Stand remains configured but will not process mobs until re-enabled.

---

## Scan Radius

Controls how far the Mob Stand searches for nearby mobs.

Larger radii cover more area but may process additional mobs.

Select this option to open the Radius Settings menu.

---

## Gravity

Controls whether the Mob Stand is affected by gravity.

### Enabled

The Mob Stand behaves like a normal Armor Stand and can fall.

### Disabled

The Mob Stand remains fixed in place.

---

## Leave Alive

Determines how many matching mobs should remain alive.

Example:

```text
Leave Alive: 5
```

If ten matching mobs are present, the Mob Stand will only process five and leave five alive.

Select this option to open the Leave Alive Settings menu.

---

## Adult Filters

Configure which adult mobs are managed by this Mob Stand.

Only enabled adult mob types will be processed.

Select this option to open the Adult Filters menu.

---

## Baby Filters

Configure which baby mobs are managed by this Mob Stand.

Only enabled baby mob types will be processed.

Select this option to open the Baby Filters menu.

---

# Menu Layout

Depending on permissions and server settings, some menu options may appear differently.

Administrators may have access to additional controls.
